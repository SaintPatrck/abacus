# Retro: consumer vendored a library from an unpushed commit

Prime Directive: everyone did the best they could given what they knew at the time.

## Scope Reviewed
A consumer repository vendored textkit from a commit that existed only in a local clone.

## Key Observations
- Start: pin vendored code only to a commit verified on the producer's remote.

## Insights
The practice of vendoring from a local working tree caused a broken consumer build because the pinned commit
was never pushed; downstream work must wait for a verified commit on origin, not a worker's report.

## SMART Action Items
1. Consumers pin vendored libraries to a commit verified on origin (owner: orchestrator; check: dispatch
   preconditions name the verified sha).

## Appreciation and Wins
The gate caught the broken import before release.

## Summary
Cross-repo dependencies wait on verified commits.
